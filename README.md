# POS Olimpo
PI Tercer Semestre Punto de Venta

 ## Descripción:
Joyería Olimpo es un punto de venta y Sistema web integral de punto de venta e inventarios para joyerías, diseñado para optimizar la gestión de productos, ventas, precios e inventario mediante una plataforma centralizada, segura y actualizada en tiempo real.


## Objetivo:
Desarrollar un módulo de punto de venta (POS) que permita gestionar las ventas de manera rápida, precisa y organizada.
